DevOps MyCloud – Tests Automatisés

Cloud privé XaaS · Tests E2E automatisés · Jenkins CI · Terraform · Selenium · SAFe · Équipe 17 personnes

MyCloud est le portail Cloud privé d'EDF permettant aux utilisateurs d'accéder à des services Cloud XaaS (VM, Load Balancer, DNS, CaaS, DBaaS). Ma mission sur 3 ans consistait à mettre en place des tests automatisés pour valider la fiabilité des workflows, la conception et publication des catalogues, et assurer un monitoring complet de la chaîne de production — réduisant la validation d'une montée de version vRA à moins de 2 heures en un clic.

Tests automatisés vRO & VMs

  • Workflows de test JavaScript dans vRealize Orchestrator pour valider les actions vRO côté serveur.
  • Fonctions pytest Python et pipelines Jenkins pour automatiser le lancement des tests sur déclencheur GitLab.
  • Templates Terraform décrivant les configurations VMs de test, Testinfra pour vérifier réseau et fichiers système.
  • Ansible pour le changement de mots de passe Linux post-déploiement, intégré dans le pipeline Jenkins.

Tests IHM Selenium & Catalog vRA

  • Classes Workspace et ServiceBroker pour l'authentification et la navigation dans le portail vRA.
  • Selenium WebDriver pour les interactions IHM : déploiement de services, vérifications fonctionnelles end-to-end.
  • Création de blueprints et catalogue items pour les déploiements de VMs standardisés.
  • Pipeline Code Stream pour relancer automatiquement tous les tests lors d'une mise à jour vRA.

Monitoring & Reporting

  • Indicateurs de pilotage sur LogInsight : supervision des déploiements et détection d'anomalies.
  • Tableaux de bord vROPS pour la supervision de l'infrastructure vSphere sous-jacente.
  • Reporting hebdomadaire automatisé via Selenium + Jenkins : génération et envoi du rapport MyCloud.
  • Résultat clé : validation d'une montée de version vRA complète en moins de 2 heures, en un seul clic.

Parcours EDF

  • Stagiaire DevOps (Sep 2020 – Mar 2021) : développement des premiers tests unitaires/non-régression, mise en place des dashboards LogInsight et vROPS.
  • CDD DevOps (Mar – Août 2021) : tests unitaires Cloud Templates DNS/Oracle, automatisation du pipeline Jenkins bout-en-bout.
  • Alternant DevOps (Sep 2021 – Sep 2023) : tests automatisés complets (unitaires, intégration, E2E), Selenium IHM, développement du VLAN validator pour MyCloud.
